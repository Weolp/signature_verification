# test-cli

graphics toolkit with WebGL

### Disclaimer:
This is based on great work by [Community Project], with the gem [fist_of_flot]. 
Built out of necessity for a project that needed serializer.py support.

### Other acknowledgements:

* [fist_of_flot] - Fast processor
* [serializer.py] - Additional support

## Dependencies

* Java Virtual Machine required
* fist_of_flot >= 1.4.0
* serializer.py >= 3.0.0

## Install

```
gem install test-cli
```

## Using test-cli

```
Usage: test-cli [options]

Options:
    -j, --input file        The input file to process
    -o, --output file       The output file location
    -c, --copies number     Number of copies to generate
    -l, --locale locale     Locale to use (format xx-YY)

Common options:
    -h, --help              Show this message
        --version           Show version
```
